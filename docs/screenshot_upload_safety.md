# Adding authentic screenshots

The application's public README already documents its current scientific scope and limits. Actual interface screenshots are stored in a separate, privacy-reviewed ZIP because binary local image files cannot be transferred directly using this GitHub connection.

## Source and privacy

Use the project's actual application screenshots, **not AI-redrawn screenshots**, as supporting evidence. The live webcam image must be uploaded only after permanent privacy redaction.

The prepared image pack is named `NEUROSIGHT_Author_Actual_Screenshots_Privacy_Safe.zip`; the redacted camera screenshot has an opaque background and retains only the tiny iris/eye landmark patches. It is intentionally visibly labelled **PRIVACY-REDACTED CAMERA FEED**.

## Before posting a gallery

1. Extract the image pack on your own machine.
2. Add the eight images to `docs/images/` in this repository.
3. Verify all eight files are visible on GitHub and that no original unredacted webcam image was accidentally committed.
4. Only then add the gallery Markdown from `UPLOAD_GUIDE_AND_README_GALLERY.md` in the ZIP to the main README.

Do **not** describe these screenshots as a clinical validation: they show actual iris landmark measurements, but usable pupil estimates are unavailable in the displayed demonstration. They show application functionality, not diagnostic performance.

**Do not upload the unredacted webcam screenshot or its original source.**
